# Передбачення: що Python прочитає з pastky.yaml

| Ключ | Моє передбачення: значення і тип | Показав perevir.py |
|---|---|---|
| svitlo | False логічне, бо off — спеціальне слово |False  логічне |
| pochatok | datetime.date(2026, 9, 28),  дата | datetime.date(2026, 9, 28)  дата |
| kod_dostupu | покаже цiле число 8 | 8  ціле число|
| limit | розпізнає як дробове число float | '1e3' рядок |
| port | не знаю що буде |  8080 ціле число |
| komentar | це спеціальний символ, що означає "null", буде None | None  порожнє |

Найбільше здивувала пастка з `limit: 1e3` — я думав, що це буде число (дробове, бо є степінь 10), а PyYAML прочитав це як звичайний рядок `'1e3'`.
