# Чому саме ці теги

| Тег | Що означає | Чому тут він, а не div |
|---|---|---|
| `header` | шапка сторінки чи розділу | div нічого не каже про зміст, а header одразу показує — це вступна частина |
| `nav` | позначає блок навігації, групу посилань для переходу по сайту | читалка розуміє, що тут навігація, і може дозволити перестрибнути одразу до неї |
| `main` | головний, унікальний вміст сторінки | div не показує, що це саме головний контент; на сторінці лише один main |
| `section` | логічно завершений розділ вмісту зі своєю темою | div не передає, що це окрема смислова частина зі своїм заголовком |
| `figure` | самостійний блок "ілюстрація + підпис", разом з figcaption | div не пов'язує підпис із конкретною картинкою, а figure+figcaption — пов'язує |

Загалом: `div` — це порожній контейнер без сенсу, він каже лише "тут якийсь блок". Семантичні теги самі повідомляють, чим саме є цей блок — і завдяки цьому браузер, пошукові системи і програми для людей з вадами зору краще розуміють структуру сторінки.
