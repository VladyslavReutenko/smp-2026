Формули в Excel / Google Таблицях
Задача й користувач: ця мова створена для людей, які працюють із таблицями даних — бухгалтерів, аналітиків, менеджерів, студентів, — і дозволяє їм рахувати, фільтрувати й агрегувати числа без знання «справжньої» мови програмування. Що спрощує: вона ховає складність циклів, індексів масивів і типізації — досить написати =SUM(A1:A10) замість писати функцію, яка проходить масив і додає значення. Де межа: коли логіка стає надто складною (багаторівневі умови, робота з зовнішніми API, великі обсяги даних), формули стають нечитабельними чи повільними, і тоді доводиться переходити на VBA, Apps Script або Python.

Регулярні вирази (regex)
Задача й користувач: мова для програмістів, адміністраторів і всіх, хто працює з текстом — щоб швидко знаходити, перевіряти чи замінювати шаблони в рядках (наприклад, номери телефонів чи email). Що спрощує: замість написання циклу з посимвольним порівнянням користувач описує шаблон декларативно, одним рядком типу \d{3}-\d{2}-\d{2}. Де межа: regex погано справляється зі структурами, що мають вкладеність (наприклад, парсинг HTML чи JSON), — там потрібен повноцінний парсер, бо мова заточена лише під лінійні текстові шаблони.

Markdown 
Задача й користувач: мова для авторів текстів (документація, нотатки, статті на GitHub чи в чатах), яким потрібне просте форматування без роботи з HTML-тегами напряму. Що спрощує: замість текст пишеш текст — синтаксис мінімальний, легко читається навіть у сирому вигляді. Де межа: коли потрібне складне форматування — таблиці з об'єднаними клітинками, точне позиціювання, стилі CSS — Markdown цього не підтримує, і доводиться вставляти «сирий» HTML або переходити на повноцінний редактор.
