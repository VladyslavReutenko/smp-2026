# Моя шпаргалка Git

| Команда | Що робить — своїми словами | Коли я її використаю |
|---|---|---|
| `git clone` | копіює весь репозиторій з GitHub на мій комп'ютер | коли треба копiювати репозиторiй на ПК |
| `git status` |показує, що змінилось: які файли нові, які змінені, чи готові вони до коміту|перевiрка файлiв до комiту|
| `git diff` |показує зміни в файлі|щоб провiрити рядок за рядком: що видалено, що додано|
| `git add` |готує файл до коміту|перед тим як буду комiтити файл|
| `git commit` |зберігає підготовлені зміни в історію|коли зберiгаю файл який робив|
| `git push` |відправляє локальні коміти на GitHub|коли хочу вiдправити зробленi файли в репозиторiй|
| `git log` | показує історію всіх комітів | коли хочу подивитися чи все правильно збереглось|

| `git branch` |показує список гілок або створює нову| коли хочу подивитись список гiлок або створити нову|
| `git checkout -b` |створює нову гілку і одразу переключається на неї| коли хочу створити i одразу переключитись |
| `git merge` |об'єднує зміни з однієї гілки в іншу| коли об'єдную змiни двох з одної в iншу |








## Передбачення

**Питання 1:** У якому розділі git status покаже eksperyment.txt?
Моя відповідь: не готовий (modified, не staged)

Git показав: файл був одночасно в обох розділах — і staged, і not staged. Я не вгадав, бо думав, що файл може бути лише в одному стані.



**Питання 2:** Який рядок покаже git diff, а який — git diff --staged?
Моя відповідь: git diff покаже Рядок 1 і Рядок 2, а git diff --staged покаже Рядок 3

Git показав: git diff показав Рядок 3, git diff --staged показав Рядок 2. Я не вгадав, бо переплутав що saved в staged, а що ні



**Питання 3:** Що потрапить у коміт без add?
Моя відповідь: Тiльки Рядок 2

Git показав: Тiльки рядок 2 як я i думав
