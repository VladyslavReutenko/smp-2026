# Моя шпаргалка Git

| Команда | Що робить — своїми словами | Коли я її використаю |
|---|---|---|
| `git clone` | копіює весь репозиторій з GitHub на мій комп'ютер | коли треба копiювати репозиторiй на ПК |
| `git status` |показує, що змінилось: які файли нові, які змінені, чи готові вони до коміту|перевiрка файлiв до комiту|
| `git diff` |показує зміни в файлі|щоб провiрити рядок за рядком: що видалено, що додано|
| `git add` |готує файл до коміту|перед тим як буду комiтити файл|
| `git commit` |зберігає підготовлені зміни в історію|коли зберiгаю файл який робив|
| `git push` |відправляє локальні коміти на GitHub|коли хочу вiдправити зробленi файли в репозиторiй|
| `git log` | показує історію всіх комітів | коли хочу подивитися чи все правильно збереглось|
